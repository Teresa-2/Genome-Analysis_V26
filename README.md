This GitHub repository contains the complete workflow and analyses performed for the Genome Analysis 2026 1MB462 course.
The project focuses on the structural and functional annotation of chromosome 3 of the moss Niphotrichum japonicum, as well as the identification of genes involved in the heat-stress response using RNA-seq data.
The workflow included:

- Quality control and trimming of sequencing reads
- Genome assembly and polishing
- Repeat identification and masking
- RNA-seq mapping
- Structural gene prediction
- Functional annotation
- Differential gene expression analysis
- Gene Ontology enrichment analysis

The analyses were performed mainly on the UPPMAX cluster using reproducible pipelines and version-controlled scripts and secondarily on a local machine
